Real-Time Collaborative Workspace

A production-ready backend built for the **PurpleMerit Backend Developer Assessment (December 2025)**.

## 🚀 Features
- JWT Authentication & Refresh Tokens
- Role-Based Access Control (OWNER, COLLABORATOR, VIEWER)
- Project & Workspace Management
- Real-time Collaboration using Socket.IO + Redis Pub/Sub
- Background Job Processing with BullMQ
- Redis Caching & Rate Limiting
- MongoDB Atlas (Primary Database)
- Swagger API Documentation
- Docker & Docker Compose
- Jest Integration Tests

## 🛠 Tech Stack
Node.js • Express • MongoDB • Redis • BullMQ • Socket.IO • JWT • Docker • Swagger
